API REST - SISTEMA CURVAA

Documentação da API

Desenvolvido em Node.js, responsável por autenticação, integração com serviços internos, envio de e-mails e persistência de dados em banco de dados.

- Tecnologias Utilizadas

  • Node.js
  • Express
  • dotenv
  • JWT para autenticação
  • Nodemailer (ou similar) para envio de e-mails
  • Banco de Dados relacional
  • Nginx
  • PM2
